# Audio für Blauis Welt

Lege hier die MP3-Dateien für den Disco Raum ab, z. B. `disco-demo.mp3`.
Danach in `games/Blauiswelt/level-disco.js` in der Liste `SONGS` einen Eintrag
mit `id`, `title`, `bpm`, `audioSrc`, `duration` (und optional `firstBeat`) ergänzen.
Fehlt die Datei, spielt automatisch der eingebaute Synth-Beat.
